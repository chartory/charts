# Contributing

Thanks for helping. This repository is generated from the Chartory site's source on every release, so pull requests
can't be merged here as they are. What helps most:

- **Bug reports.** A chart draws wrong, a label collides, a type fails to install or typecheck: open an issue with the
  chart's slug (for example `sankey`), the size, your React and framework versions and, if you can, the data.
- **Requests.** A chart type you need, or a prop a type is missing: open an issue and say what question the chart
  should answer.
- **Fixes.** If you found the fix, put the diff in the issue. It lands in the next release and you get the credit in
  the changelog.

Security issues: write to hello@usechartory.com instead of opening an issue.
